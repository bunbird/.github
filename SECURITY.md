# Security policy

This is the default policy for every Bunbird repository that does not carry its own `SECURITY.md`.

## Reporting a vulnerability

Do not report a suspected vulnerability in a public issue, pull request or chat channel.

Use the repository's **Security** tab to open a private security advisory, or write to support@bunbird.com. Include what you found, the affected file, commit or deployment, steps to reproduce and the impact you believe it has. A minimal proof of concept is more useful than a broad claim.

We acknowledge the report, assess it and agree a disclosure date with you. Do not publish details until a fix is out or that date has passed.

## Supported code

Fixes are made on `main`. If you found the problem in an older commit, report it anyway and name the commit you tested.
